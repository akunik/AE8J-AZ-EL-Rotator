# AE8J-AZ-EL-Rotator
Azimuth &amp; Elevation antenna rotator for satellite tracking. Rotator is completely 3D printed. I'm using PETG but any suitable filament can be used.
Stepper motors are 23HE22-2804S with a holding torque of .9 ft-lb. 3D printed split ring planetary gear reducers are used in each axis. An additional 
2:1 spur gear reduction increases the theoretical holding torque to 90 ft-lbs.
